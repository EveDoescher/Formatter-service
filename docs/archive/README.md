# Archive

Documentos históricos que representam decisões, planos e referências de versões anteriores do projeto.

O conteúdo aqui **não é autoritativo**. Pode estar desatualizado em relação ao código atual.

Para documentação ativa, consulte:
- `docs/guide/` — regras arquiteturais e convenções de nomenclatura
- `docs/components/` — referência de componentes ativos
- `docs/roadmap/` — planos pendentes de implementação
- `docs/superpowers/plans/` — planos prospectivos ainda não implementados

## Estrutura

```
archive/
├── components/         ← docs de componentes escritos durante implementação inicial
├── roadmap/            ← roadmap original e checkpoints de etapas concluídas
└── superpowers/
    ├── plans/          ← planos de implementação das Fases 1–5 (já executadas)
    └── specs/          ← specs de design já executadas
```
